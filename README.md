# 💊 MedMate – จัดการยาในบ้านให้ง่าย

แอปเล็กๆ ที่ช่วยดูแลยาในบ้าน ใช้ภาษาไทย เปิดบนมือถือได้ ใช้ออฟไลน์ได้ และข้อมูลอยู่ในเครื่องของคุณเอง

> ✨ **ไม่ต้องเขียนโค้ดเป็นก็สร้างได้** แค่บอก AI ว่าอยากได้อะไร แล้วดูผลลัพธ์ ปรับไปเรื่อยๆ จนพอใจ ค่อยทำแอปจริง

## 🚀 เริ่มต้นยังไง

1. เปิดโปรเจกต์นี้กับ AI ผู้ช่วย (Claude Code)
2. **ครั้งแรกครั้งเดียว:** AI จะจดสิ่งที่เราคุยกันลงเอกสาร ถ้ายังไม่พอจะ **ถามสั้นๆ ไม่เกิน 20 ข้อ** เช่น ใครจะใช้แอป และสามอย่างแรกที่แอปต้องทำได้คืออะไร ตอบแบบง่ายๆ ได้เลย ไม่มีคำตอบที่ผิด 😊
3. หลังจากนั้นไม่มีการถามเป็นรอบแล้ว คุณพิมพ์บอก AI ได้อิสระเลยว่าอยากเปลี่ยนหน้าไหน เช่น "ทำปุ่มเพิ่มยาให้ใหญ่ขึ้น" หรือ "เพิ่มช่องวันหมดอายุ"
4. AI จะแก้ให้ดู คุณบอกว่าชอบหรือยัง แล้วปรับต่อ ทำซ้ำได้ไม่จำกัด 🔁
5. เมื่อพอใจแล้ว บอกว่า "โอเค ทำแอปจริงได้" AI จึงจะเริ่มทำแอปจริง

## 🙋 AI จะถามคุณก่อนเมื่อ
- จะลบหรือย้ายไฟล์
- ไม่แน่ใจว่าคุณต้องการอะไร (AI จะไม่เดาแล้วบันทึกว่าเป็นความต้องการของคุณ)

ส่วนการบันทึกงานเก็บเวอร์ชัน AI ทำให้เองอัตโนมัติ คุณไม่ต้องรู้เรื่องนี้เลย ✅

## 📱 ติดตั้งบน Android
1. อัปโหลดไฟล์ในโฟลเดอร์นี้ไปที่เว็บโฮสต์ https (เช่น GitHub Pages)
2. เปิดลิงก์ไปที่ `medmate-app.html` ด้วย Chrome บน Android
3. กดเมนู ⋮ → **ติดตั้งแอป** (Install app) หรือ **เพิ่มลงหน้าจอหลัก**

หมายเหตุ: ข้อมูลยาเก็บในเครื่อง ใช้ออฟไลน์ได้ ยังไม่ซิงก์ข้ามเครื่อง
