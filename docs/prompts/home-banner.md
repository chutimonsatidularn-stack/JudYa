> ก่อนเริ่ม: อ่าน CLAUDE_HANDOFF.md, DESIGN_SYSTEM.md, judya-screen-spec-v0.7.md (หน้า Home), judya-acceptance-criteria-v0.7.md

## เป้าหมาย
การ์ดต้อนรับบนหน้า Home แทนรูปบ้านด้วยภาพ badge 3 แบบ เปลี่ยนตามสถานะ และเอา emoji มือโบก (👋) ข้างคำว่า "สวัสดีค่ะ" ออก

## ไฟล์ภาพ (วางที่ assets/banner/ — SVG ใช้เป็นหลัก, PNG เป็น fallback)
| สถานะ (key) | ไฟล์ | เงื่อนไขแสดง |
|---|---|---|
| `normal` | judya-banner-normal.svg | ค่าเริ่มต้น ไม่มีเรื่องเร่งด่วน |
| `reminder` | judya-banner-reminder.svg | มีรายการใกล้ถึงเวลากินยา หรือยาใกล้หมด/ถึงเวลาสั่งซื้อ |
| `family` | judya-banner-family.svg | มีสมาชิกในบ้านที่ต้องดูแล (มีรายการค้างของคนอื่นที่ไม่ใช่ตัวเอง) |

ขนาดแสดงผล: กว้าง ~38% ของการ์ด ชิดขวา จัดกึ่งกลางแนวตั้ง รักษาสัดส่วนเดิม (ห้ามยืด) — ภาพ normal สูงกว่าอีกสองภาพ ให้ใช้กล่องสูงคงที่แล้ว `contain`
ภาพเป็นพื้นโปร่งใส ห้ามใส่พื้นหลัง/เงาเพิ่ม

## ลำดับความสำคัญเมื่อหลายสถานะพร้อมกัน (ให้ฉันยืนยันก่อนเขียน)
เสนอ: `reminder` > `family` > `normal`
→ ถ้าไม่ตรงกับที่ต้องการ ให้ถามฉันก่อน

## หลักการเขียนโค้ด
1. **ฟังก์ชันเดียว** `getHomeBannerState(input): 'normal'|'reminder'|'family'` เป็น pure function ไม่ผูกกับ UI ไม่อ่านเวลาเอง (รับ `now` เป็นพารามิเตอร์) เพื่อเทสต์ง่าย
2. **Map เดียว** `HOME_BANNERS = { normal, reminder, family }` เก็บ path ภาพ + alt text ภาษาไทย ที่เดียว ห้าม hard-code path ใน component
3. **Component เดียว** `<HomeBanner state />` ใช้ซ้ำได้ ถ้าสถานะไม่รู้จัก ให้ fallback เป็น `normal`
4. ข้อความในการ์ด (คำทักทาย/จำนวนรายการ/ปุ่ม "ดูทันที") ยังมาจากโค้ดเดิม ไม่ฝังในภาพ ห้ามคัดลอกโค้ดการ์ดซ้ำ 3 ชุด
5. เอา emoji 👋 ออกจากสตริงทักทาย (ค้นทั้ง repo รวม i18n/strings) และตรวจว่าไม่มีที่อื่นใช้ซ้ำ
6. **ความปลอดภัย:** โหลด SVG ผ่านแหล่ง asset ของแอพเท่านั้น (ห้ามรับ path/URL จากผู้ใช้หรือเซิร์ฟเวอร์) ห้าม inline SVG ที่มาจากภายนอก; ใส่ `alt`/accessibilityLabel; ข้อมูลยา/สมาชิกในบ้านที่ใช้ตัดสินสถานะไม่ถูกส่งออกนอกเครื่อง/log
7. ประสิทธิภาพ: preload ภาพ `normal`, ภาพอื่นโหลดเมื่อต้องใช้ (เจ้าของตัดสินใจ 2026-10-09: ใช้ไฟล์ภาพตามที่ส่งมา ไม่ต้องลดให้เหลือ ~300 KB; ภาพรวมปัจจุบัน ~374 KB)
8. ถ้าต้องมีธีมมืด: เตือนฉันก่อน (ภาพเป็นโทนสว่าง)

## เทสต์ที่ต้องมี (ตาม acceptance criteria)
- `getHomeBannerState`: ครบ 3 สถานะ + กรณีหลายสถานะพร้อมกัน + ไม่มีข้อมูล → `normal`
- render 3 สถานะ ไม่ยืดภาพ ไม่ทับข้อความ/ปุ่ม ที่ความกว้างจอ 360 / 390 / 430
- ไม่มี 👋 เหลืออยู่ใน repo

## ส่งงานเมื่อเสร็จ
สรุปไฟล์ที่แก้, ภาพหน้าจอ Home 3 สถานะ, ผลเทสต์, และจุดที่ยังไม่แน่ใจ (ถ้ามี)
