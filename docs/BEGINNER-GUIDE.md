# คู่มือมือใหม่: ใช้ Claude Code สร้างแอป JudYa

คู่มือนี้เขียนสำหรับคนที่ไม่เคยเขียนโค้ดและไม่เคยใช้ Claude Code อ่านจบใน 5 นาที

## 1. Claude Code คืออะไร
- คือ Claude ที่ **ลงมือแก้ไฟล์โค้ดจริงใน repo (GitHub) ให้เรา** ต่างจากแชตธรรมดาที่แค่คุยและสร้างหน้าตัวอย่าง
- เราพิมพ์เป็นภาษาไทยได้ ไม่ต้องรู้คำสั่งหรือภาษาโปรแกรม
- มันทำงานบน "สำเนา" ของโปรเจกต์ใน branch แยก แอปจริงบนมือถือจึงไม่เปลี่ยนจนกว่าเรากดรวมงาน (Merge)

## 2. การตัดสินใจที่เลือกไว้ให้แล้ว (เปลี่ยนได้ทุกข้อ)
| เรื่อง | ที่เลือก |
|---|---|
| วิธีรัน | เว็บ **claude.ai/code** หรือแท็บ Code ในแอป Claude บนมือถือ (ไม่ต้องติดตั้งอะไร) |
| วิธีสร้าง | แบบ **B**: เขียนใหม่ให้อ่านง่าย (React + TypeScript + ชุดทดสอบ) ปล่อยที่ลิงก์ GitHub Pages เดิม |
| ความปลอดภัยของแอปเดิม | ทำใน branch แยก + Pull Request (PR) แอปในมือถือยังใช้ได้ตามเดิมจนกว่าจะอนุมัติ |
| ลบข้อมูลแพ้ยา | ไม่เก็บประวัติ (Q-A) |
| หน้าที่ยังไม่ได้ออกแบบ | ให้ Claude Code ทำร่าง แล้วหยุดให้เจ้าของดูก่อนทำต่อ |

## 3. ศัพท์ที่จะเจอ
| คำ | แปลว่า |
|---|---|
| repo | โฟลเดอร์โปรเจกต์บน GitHub (ของเรา: `MedMate`) |
| branch | สำเนาสำหรับทดลองแก้ ไม่กระทบของจริง |
| commit | การบันทึกงานหนึ่งครั้ง พร้อมคำอธิบาย |
| diff | หน้าที่โชว์ว่าบรรทัดไหนถูกเพิ่ม (เขียว) / ลบ (แดง) |
| PR (Pull Request) | คำขอให้นำงานจาก branch ไปรวมกับของจริง เรากดอนุมัติเอง |
| merge | การรวมงานเข้าของจริง (แอปเปลี่ยนตอนนี้) |
| ADR | บันทึกการตัดสินใจสำคัญ (เป็นไฟล์ในโปรเจกต์) |
| test | โปรแกรมเล็กๆ ที่ตรวจว่าการคำนวณถูกต้อง |

## 4. ขั้นตอนทีละข้อ
### ก่อนเริ่ม (ทำครั้งเดียว)
1. **สำรองข้อมูลยาจริง**: เปิดแอปในมือถือ กดปุ่ม "สำรอง" เก็บไฟล์ไว้ในที่ปลอดภัย **ห้ามอัปโหลดขึ้น GitHub**
2. **เช็กแพ็กเกจ**: Claude Code บนเว็บต้องใช้แพ็กเกจ Pro, Max หรือ Team (ตรวจที่หน้าตั้งค่าบัญชี claude.ai) ใช้โควตาร่วมกับการแชตปกติ
3. **ใส่ชุดไฟล์เข้า repo**: แตก zip → เข้า GitHub repo `MedMate` → Add file → Upload files → ลากโฟลเดอร์ `docs`, `reference`, `prototype`, `HANDOFF.md` ขึ้นไป → Commit changes
   - (ถ้าไฟล์ชื่อซ้ำกับของเดิม ให้เลือกแทนที่เฉพาะ `docs/requirements.md`)

### เริ่มใช้
4. เปิด **claude.ai/code** → ล็อกอินบัญชีเดียวกัน
5. กดเชื่อม GitHub → ติดตั้ง **Claude GitHub App** → เลือก repo `MedMate` เท่านั้น
6. เลือก repo + branch `main` → เริ่ม session ใหม่
7. คัดลอกทั้งไฟล์ `docs/prompts/judya-v07-build.md` วางเป็นข้อความแรก แล้วส่ง
8. Claude Code จะ **อ่านเอกสารก่อนและถามคำถามเป็นตัวเลือก** ให้ตอบ ถ้าไม่เข้าใจให้พิมพ์ว่า "อธิบายง่ายๆ ก่อน"
9. เมื่อถูกถามว่าเริ่มสร้างจริงไหม ตอบชัดๆ: **"อนุมัติ prototype เริ่มสร้างจริงได้"** (ตามกฎใน AGENTS.md)

### ระหว่างทำงาน
10. มันจะหยุดเป็นช่วงๆ (checkpoint) บอกว่าทำอะไรแล้วและให้ลองอะไรบนมือถือ
11. ดูผลที่ลิงก์ทดสอบ แล้วบอกว่าผ่านหรือต้องแก้ เป็นภาษาไทยธรรมดา
12. อยากแก้อะไร พิมพ์สั่งได้เลย เช่น "ปุ่มเล็กไป ขยายหน่อย" หรือ "ตัวหนังสือสีจางอ่านยาก"
13. เมื่อพอใจ กด **Create PR** แล้วกด **Merge** ด้วยตัวเอง (ก่อนกด ให้เทสบนมือถือก่อนเสมอ)

## 5. ข้อควรจำ
- ถ้ามันถามอะไรที่ไม่เข้าใจ **ถามกลับได้เสมอ** ไม่ต้องเดา
- งานค้างได้: ปิดหน้าจอแล้วกลับมาเปิด session เดิมเพื่อทำต่อ (ถ้าหมดเวลา ให้เปิดซ้ำ ระบบคืนบทสนทนาให้)
- ก่อนจบทุกครั้ง ให้สั่งว่า "อัปเดต HANDOFF.md ส่วนสถานะ" เพื่อให้แชตหน้าทำต่อได้
- ถ้าอยากออกแบบหน้าใหม่ต่อในแชต Claude ปกติ ใช้ `HANDOFF.md` ข้อ 3
- ข้อมูลยาเป็นข้อมูลส่วนตัว: อย่าส่งไฟล์สำรองหรือภาพถ่ายยาจริงในแชต/commit
- คอร์สฟรีสำหรับมือใหม่: academy.claude.com → "Claude Code 101"

## 5b. แอปใช้งานได้แล้ว: อยากเปลี่ยนอะไรทำอย่างไร
แอปจริงอยู่ที่ `https://chutimonsatidularn-stack.github.io/JudYa/` (ติดตั้งลงหน้าจอหลักมือถือได้)

**1. บอก Claude ให้ชัด 3 อย่าง**
- **หน้าไหน** เช่น "หน้าเพิ่มยา" "หน้าสั่งยา" (ใช้เลขหน้าได้ เช่น "หน้า 08")
- **อยากเปลี่ยนอะไร** เช่น "ปุ่มบันทึกเล็กไป" "อยากให้แสดงราคาต่อแผงด้วย"
- **เหตุผลหรือสถานการณ์** เช่น "ตอนเพิ่มยาพ่อแล้วหาช่องวันหมดอายุไม่เจอ"
- ส่งภาพหน้าจอมาด้วยได้ ช่วยให้เข้าใจเร็วมาก ถ้าเจอข้อผิดพลาด บอกด้วยว่ากดอะไรก่อนมันเกิด

**2. บอกทีละเรื่อง** Claude จะทำทีละเรื่องแล้วให้คุณดู ไม่ต้องรอรวมทั้งหมด

**3. Claude ทำให้เอง** แก้เอกสารข้อกำหนดก่อน แล้วแก้แอป ทดสอบ บันทึกและส่งขึ้น PR ถ้าเรื่องไหนมีหลายทางเลือกที่ต่างกันจริง จะถามก่อน

**4. คุณต้องกด Merge** (Claude ไม่ merge เอง) เมื่อ Claude บอกว่าเสร็จ:
1. เปิดหน้า PR ใน GitHub กด **Merge pull request** แล้ว **Confirm merge**
2. ระบบเผยแพร่ทำงานเอง ประมาณ 1–2 นาที ดูที่แท็บ **Actions** ให้เป็นเครื่องหมายถูกสีเขียว (ถ้าเป็น ❌ สีแดง ส่งภาพให้ Claude)
3. บนมือถือ **ปิดแอปให้สนิทแล้วเปิดใหม่ 1–2 ครั้ง** จึงจะได้ฉบับใหม่ ข้อมูลที่กรอกไว้ไม่หาย

**ข้อควรรู้**
- กด **สำรอง** ในหน้าตั้งค่าเป็นระยะ โดยเฉพาะก่อนแก้เรื่องใหญ่ ไฟล์สำรองเก็บในที่ปลอดภัย อย่าส่งในแชตหรือ commit
- ข้อมูลอยู่ในมือถือเครื่องเดียว ถ้าเปลี่ยนเครื่องหรือล้างข้อมูลเบราว์เซอร์ ให้ "นำเข้า" ไฟล์สำรอง
- ถ้าการเปลี่ยนแปลงกระทบข้อมูลที่เก็บไว้ Claude จะบอกก่อนทุกครั้ง

## 6. ถ้าติดปัญหา
| อาการ | ทำอย่างไร |
|---|---|
| มองไม่เห็น repo | ตรวจว่า Claude GitHub App ได้รับสิทธิ์ repo `JudYa` (เดิมชื่อ `MedMate`) |
| กด Merge แล้วแอปบนมือถือยังเหมือนเดิม | รอ 1–2 นาทีให้ Actions เป็นสีเขียว แล้วปิดแอปให้สนิทและเปิดใหม่ 1–2 ครั้ง |
| โควตาหมด | รอรีเซ็ต หรืออัปเกรดแพ็กเกจ งานที่ทำแล้วอยู่ใน branch ไม่หาย |
| แอปบนมือถือข้อมูลหาย | อย่าตกใจ เอาไฟล์สำรองจากข้อ 1 มา "กู้คืน" |
| ผลไม่เหมือนรูปที่อนุมัติ | บอกเลขหน้า เช่น "หน้า 08 ไม่เหมือนรูป" แล้วให้มันเทียบกับ `docs/design/screens/` |
